# research

Agents that look something up and report what they found: recon inside a
codebase, recon on the web. What they share is the job, not the subject. An
agent about the network belongs here only if looking things up is what it does.

The list is in [`../README.md`](../README.md), generated from each `AGENT.md`.
Rules for adding one are in [`../AGENTS.md`](../AGENTS.md).
