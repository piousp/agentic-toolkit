# research

Agents that look something up and report what they found: local recon of a codebase, web recon, analysis of a document or a diff. The category names the job, not the subject matter, so an agent about the network still belongs here only if looking things up is what it does.

The list is in [`../README.md`](../README.md), generated from each `AGENT.md`. Rules for adding one are in [`../AGENTS.md`](../AGENTS.md).
