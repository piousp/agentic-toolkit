# general

Agents that fit any task: planning, execution, critique, and analysis measured
against criteria the caller brings instead of a subject of its own.

Nothing here assumes the work is code. An agent whose subject also has a
category of its own can live in either place, and no file here points at an
agent through its category.

The list is in [`../README.md`](../README.md), generated from each `AGENT.md`.
Rules for adding one are in [`../AGENTS.md`](../AGENTS.md).
