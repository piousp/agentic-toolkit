# general

Agents usable in any task: planning, execution, critique, and analysis that measures an artifact against the criteria the caller brings rather than against a domain of its own.

The category is navigation only, never a claim about the subject. An agent whose subject also has a category of its own can live in either place, and nothing here references an agent by its category.

The list is in [`../README.md`](../README.md), generated from each `AGENT.md`. Rules for adding one are in [`../AGENTS.md`](../AGENTS.md).
