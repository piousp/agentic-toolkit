# coding

Agents that plan a change to code and then carry it out: public contracts,
design decisions, test seams and ordered steps. The category names the
deliverable, not the language or the framework, so a plan about a Go service
and a plan about a TypeScript one land in the same place.

General task, research and writing plans belong to `general`.

The list is in [`../README.md`](../README.md), generated from each `AGENT.md`.
Rules for adding one are in [`../AGENTS.md`](../AGENTS.md).
