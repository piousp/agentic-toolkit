# general

Skills that carry no domain of their own: the same instructions apply to code, prose or research, and a caller can load one without knowing what the task is about.

The category is navigation only, never a claim about the subject. A skill whose subject also has a category of its own can live in either place, and nothing here references a skill by its category.

The list is in [`../README.md`](../README.md), generated from each `SKILL.md`. Rules for adding one are in [`../AGENTS.md`](../AGENTS.md).
