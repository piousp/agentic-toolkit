# general

Skills usable as they are in any task. They carry no domain: the same instructions apply to code, prose or research. A skill that needs a qualifier to say where it belongs ("for code", "for papers") belongs in the category that names it, not here.

The list is in [`../README.md`](../README.md), generated from each `SKILL.md`. Rules for adding one are in [`../AGENTS.md`](../AGENTS.md).
