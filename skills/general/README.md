# general

Skills with no domain of their own. The same instructions apply to code, prose
or research, and a caller can load one without knowing what the task is about.

A skill whose subject also has a category can live in either place. Nothing
routes on the category, only on the name and the description.

The list is in [`../README.md`](../README.md), generated from each `SKILL.md`.
Rules for adding one are in [`../AGENTS.md`](../AGENTS.md).
