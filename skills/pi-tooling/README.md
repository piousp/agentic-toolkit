# pi-tooling

Skills that depend on how the reference harness is built: where it keeps its sessions, which variables it exports, what it writes to disk. Only material tied to that harness's own layout belongs here. A skill that merely happens to be used with it does not.

The list is in [`../README.md`](../README.md), generated from each `SKILL.md`. Rules for adding one are in [`../AGENTS.md`](../AGENTS.md).
